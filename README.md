# FRONT

Визуальный интерфейс решения Secure Messaging Platform

### Требования к визуальному интерфейсу

#### Иерархия требований к визуальному интерфейсу

```
    FRONT
    ├── главный экран (доступно всем)
    │   ├── отображение списка ролей с полномочиями доступа к экранам (эндпоинт GET /roles) 
    │   ├── отображение списка включённых методов шифрования (эндпоинт /getEnabledEncryptionMethods)
    │   └── переход на экраны почты, входа, регистрации
    │       ├── навигация в header (для авторизованных logout-кнопка)
    │       └── навигация на самой странице
    ├── рабочий стол (workspace) 
    │   ├── виджет шифрования сообщения. Контракт: исходный текст + метод шифрования. (эндпоинт /encrypt) (для авторизованных пользователей)
    │   ├── виджет дешифрования сообщения. (эндпоинт /decrypt) (для авторизованных пользователей)
    │   │    ├── для RSA контракт: шифртекст + private key в формате PEM + тип метода шифрования (RSA)
    │   │    └── для Кузнечика: шифртекст + ключ + тип метода шифрования(Kuznechik)
    │   ├── журнал сообщений пользователей (эндпоинт /getAllMessages) (для admin - всех пользователей, для user - только собственные)
    │   │   └── виджет сообщения
    │   │       ├── DTO: тип и величина ключа(RSA-32768/Kuznechik), временная метка, исходный текст, шифртекст, pubkey, private key (RSA PKCS #1). Для Кузнечика вместо pub/private key - ключ и вектор инициализации IV в hex формате. Если ключи для записи недоступны не отображать.
    │   │       ├── проверка из шифртекста - операция дешифрования (эндпоинт /decrypt)
    │   │       ├── кнопка формирования PDF + ЭЦП (эндпоинт загрузки pdf-документа подписанного ЭЦП. документ содержит ЭЦП. /exportPdfWithSignature) (для авторизованных пользователей)
    │   │       └── кнопка проверки подлинности подписи документа
    │   └── страница администратора (только для администраторов)
    │        ├── информация о полномочиях роли администратора
    │        ├── окно отображения доступных в системе методов шифрования (/getAllEncryptionMethods)
    │        │   └── переключение доступности метода шифрования (/setEncryptionMethodAvailability)
    │        ├── создание пользователя (логин, почта, пароль, роль пользователя) (опционально) (POST /user - возвращает список кодов восстановления)
    │        └── список пользователей (GET /users). DTO: логин, почта, роль.
    ├── вход
    │   ├── форма логина (логин, пароль, ссылка на восстановление пароля). (эндпоинт для логина /login)
    │   │   ├── фактор 1. пароль (/login)
    │   │   ├── фактор 2. код из письма (/confirmEmailCode)
    │   │   └── фактор 3. код восстановления, сгенерированный при регистрации (/confirmDisposableCode)
    │   └── форма восстановления пароля: запрос письма на почту (/restorePassword) -> ввод кода подтверждения + токена сброса + нового пароля (/confirmNewPassword)
    └── регистрация
        ├── шаг 1. форма регистрации (логин, почта, пароль, потверждение пароля) (эндпоинт /signup - возвращает список кодов восстановления) (проверка регулярными выражениями)
        └── шаг 2. отображение одноразовых кодов
```
