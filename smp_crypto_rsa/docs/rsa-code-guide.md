# RSA: как запустить и прочитать код

Модуль для [задачи CRYPTO-1 (#7)](https://github.com/JugadorProgrammer/secure-messaging-platform/issues/7). Он генерирует пары ключей, читает готовые ключи из JSON и выполняет числовые операции RSA. Примеры из этой памятки запускаются отдельно от мессенджера и используют маленький учебный ключ.

## Быстрый запуск

Открой терминал в папке `smp_crypto_rsa`. Нужен Python 3.10 или новее, дополнительные библиотеки не требуются.

```powershell
python rsa_demo.py demo
python rsa_demo.py test
```

Первая команда показывает пример `65 → 2790 → 65`: шифрование и два варианта расшифрования. В консоли числа выводятся в hex: `0x41 → 0xae6 → 0x41`. Вторая команда прогоняет 22 автотеста и сверяет результаты 20 контрольных операций с ожидаемыми.

## Проследить один вызов

1. В `rsa_demo.py` команда `demo` запускает `_demo()`. Она берёт из `test_vectors/rsa_demo.json` учебный ключ и ожидаемые результаты. В примере передаётся целое число 65.
2. В `rsa_core/rsa.py` функция `rsaep` проверяет открытый ключ и диапазон `0 ≤ m < n`. Затем она вызывает `mod_pow(m, e, n)` из `rsa_core/arithmetic.py`. Получается шифртекст 2790.
3. В том же файле `rsadp_reference` расшифровывает число по модулю `n`. Функция `rsadp_crt` вызывает `_crt_value`: та считает отдельно по меньшим модулям `p` и `q` и собирает результат. Перед возвратом `rsadp_crt` снова применяет открытую операцию и проверяет, что получила исходный шифртекст. Оба способа возвращают 65.

## Пример вызова функций из Python

Этот фрагмент можно запустить из папки `smp_crypto_rsa`. Все числа ключа взяты из учебного примера.

```python
from rsa_core.rsa import make_private_key, rsaep, rsadp_reference, rsadp_crt

key = make_private_key(n=3233, e=17, d=413, p=61, q=53)
ciphertext = rsaep(key.public_key(), 65)
print(ciphertext, rsadp_reference(key, ciphertext), rsadp_crt(key, ciphertext))
# 2790 65 65
```

## Где искать остальное

| Что нужно понять | Где смотреть |
|---|---|
| Генерация ключа | `rsa_core/rsa.py` → `generate_key_pair`: выбирает разные простые множители, вычисляет показатели и проверяет пробный цикл. |
| Поиск простых чисел | `rsa_core/primes.py` → `generate_prime` и `is_probable_prime`. |
| Чтение готового ключа | `rsa_core/key_io.py` → `load_json_key`: читает JSON, сверяет поля и передаёт их в `make_private_key`. |
| Подпись числа и обратная проверка | `rsa_core/rsa.py` → `rsasp1` и `rsavp1`. Первая вызывает закрытую операцию, вторая — открытую. Сравнение с ожидаемым числом показано в `_demo()`. |
| Проверки | `tests/test_arithmetic.py`, `tests/test_rsa.py` и контрольные данные в `test_vectors/`. |

Для показа команде достаточно запустить `demo` и открыть `_crt_value`: объяснить, какие два остатка вычисляются и как проверяется результат. Сообщения в мессенджере потребуют отдельной обёртки: это ядро принимает и возвращает числа, а операции числовой подписи сами по себе не реализуют подпись сообщений.
