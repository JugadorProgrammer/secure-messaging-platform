# RSA для Secure Messaging Platform

Самостоятельный модуль для задачи [CRYPTO-1 (#7)](https://github.com/JugadorProgrammer/secure-messaging-platform/issues/7). Его можно запустить отдельно от остальных сервисов SMP. Нужен Python 3.10 или новее, сторонние пакеты не требуются.

## Запуск

Откройте терминал в распакованной папке `smp_crypto_rsa`:

```console
python rsa_demo.py demo
python rsa_demo.py test
python rsa_demo.py
```

`demo` использует встроенный учебный пример. Он шифрует число 65 в 2790 и восстанавливает 65 двумя способами. Для примитива подписи ожидается `65 → 588 → 65`. Консоль показывает числа в hex: `0x41`, `0xae6` и `0x24c`. Команда `test` проверяет контрольные примеры и запускает автотесты. Запуск без аргументов открывает меню: в пункте 1 можно выбрать учебный ключ. Ввод чисел в меню — в hex, например `41` или `0x41` для десятичного 65.

Для готового ключа укажите каталог с четырьмя JSON, например `../keys`:

```console
python rsa_demo.py key-check --key-dir ../keys
python rsa_demo.py bench --key-dir ../keys
```

Проверка и замер используют один шифртекст для обеих версий расшифрования и проверяют результат числовой подписи. По умолчанию загрузчик проверяет связи параметров. Флаг `--check-primes` дополнительно запускает 64 раунда Миллера — Рабина для каждого множителя. На большом ключе этот режим занимает значительно больше времени. `Ctrl+C` прерывает вычисление. Готовый ключ при запуске этих команд не пересоздаётся.

Импорт ожидает:

| Файл | Поля |
| --- | --- |
| `private_key.json` | `n`, `e`, `d`, `p`, `q`; необязательно `dP`, `dQ`, `qInv` |
| `public_key.json` | `n`, `e` |
| `p.json`, `q.json` | `prime` в каждом файле |

Поля — строки в hex. Файлы готового ключа в архив не входят. Генерация запускается отдельно по явной команде, например `python rsa_demo.py bench --generate --bits 2048`. Доступны 2048, 4096 и 32768 бит. Этот режим измеряет генерацию и операции раздельно. Новую пару на 32768 бит для данного комплекта не генерировали.

## Как читать исходники

| Файл | Что в нём |
| --- | --- |
| `rsa_core/arithmetic.py` | Евклид, обратное число, возведение в степень по модулю оконным методом с умножением Монтгомери |
| `rsa_core/key_io.py` | Чтение JSON, разбор hex и сверка параметров |
| `rsa_core/rsa.py` | Модели ключей, генерация через функцию Кармайкла, RSAEP, обычное RSADP и RSADP через CRT, числовые примитивы RSASP1 и RSAVP1 |
| `rsa_core/primes.py` | Случайные кандидаты, отсев малых делителей и тест Миллера — Рабина |
| `rsa_demo.py` | Меню, примеры, проверка готового ключа и замер |
| `tests/`, `test_vectors/` | Автотесты и открытые учебные данные с ожидаемыми ответами |

CRT заменяет одно возведение в степень по модулю `n` двумя вычислениями по меньшим модулям `p` и `q`. Перед выдачей результата модуль повторно применяет открытую операцию и сверяет её ответ с исходным числом.

## Что проверено

На Windows x64, Python 3.12.14, прошли 22 автотеста и 20 проверок по контрольным примерам. На импортированном ключе с модулем 32768 бит обе версии расшифрования и проверка подписи восстановили исходное число. В одном прогоне обычное расшифрование заняло 54,48 с, через CRT — 18,22 с. Это измерение одного шифртекста, а не норматив. Полный замер: `bench_32768.json`. Простота множителей повторно не проверялась; время генерации в отчёте не указано, поскольку использовалась готовая пара.

Модуль выполняет операции над целыми числами `0 ≤ x < n`. Сейчас это учебное ядро: подключение к сервису SMP, схема подписи сообщения и безопасная упаковка сообщения для реального шифрования находятся вне этого комплекта.
